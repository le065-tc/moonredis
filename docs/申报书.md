# 项目申报书

## 基本信息

- 项目名称：moonredis —— MoonBit 原生 Redis 协议兼容内存数据库服务器
- GitHub 仓库链接：https://github.com/le065-tc/moonredis
- mooncakes 发布链接：https://mooncakes.io/packages/le065-tc/moonredis
- 项目方向：MoonBit 系统编程与基础设施库，Redis 协议兼容的内存数据库服务器，native 优先、可跨平台运行
- 适用场景：本地开发缓存、教学与演示、边缘/嵌入式内存数据库、MoonBit 服务端组件
- 是否为移植项目：否，原创项目

## 项目简介

moonredis 是使用 MoonBit 从零实现的 Redis 协议兼容服务器：从 RESP 编解码、五种核心数据结构、键过期、事务（MULTI/EXEC/DISCARD）、发布订阅（SUBSCRIBE/UNSUBSCRIBE/PUBLISH）到 AOF 追加持久化均自研实现，核心协议与存储层为纯 MoonBit，网络层为仓库内自带的跨平台 C 桥接（Windows Winsock / POSIX socket），不依赖第三方网络库。已检索并对比 mooncakes 与 GitHub 上的 MoonBit 项目（oboard/moonbit-redis、Metalymph/valkey 等均为 Redis 客户端），确认 MoonBit 生态中尚无 Redis 协议服务端实现，本项目与该方向错开。仓库已包含核心库、服务器、CLI、Python 示例、兼容性文档、26 个单元测试与端到端冒烟测试，GitHub Actions 覆盖 native 构建与测试。

## 核心功能范围

- 协议层：RESP2 全类型 + RESP3 子集（Null/Boolean/Double/Push），增量解析与编码，兼容 redis-cli 与常见客户端；
- 数据模型：String / List / Hash / Set / ZSet 五种数据结构，键级 TTL（惰性过期 + 周期清扫）；
- 命令系统：70+ 常用命令，类型与参数错误检查，COMMAND / INFO / CONFIG / CLIENT 等服务器命令；
- 事务与发布订阅：MULTI / EXEC / DISCARD；SUBSCRIBE / UNSUBSCRIBE / PUBLISH；
- 持久化：RESP 格式 AOF 追加写入与启动重放，Windows 下支持中文/Unicode 路径；
- 工程化：自带 CLI、Python 快速开始示例、兼容性文档、26 个单元测试、端到端冒烟测试、GitHub Actions CI。

## 移植或参考说明

本项目为原创项目，未移植既有开源项目的代码。协议行为参考 Redis 公开的 RESP 协议规范与命令语义；开发前已检索 mooncakes 与 GitHub 上的相关项目，确认 MoonBit 生态中仅有 Redis 客户端、无服务端实现，避免功能与命名重合。项目许可：Apache-2.0。
